# Télémétrie du Worker Fixer

## Signaux recommandés

- id du job de remédiation ;
- id de la vulnérabilité ;
- nom de la règle de remédiation ;
- nombre de patchs générés ;
- résultat de validation ;
- classe d'erreur du fournisseur externe lorsqu'un fournisseur Git est utilisé.

## Exigences d'audit

Toute remédiation acceptée doit être traçable de l'action utilisateur jusqu'au
changement généré et au statut final.
