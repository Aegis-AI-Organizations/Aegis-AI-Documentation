The **Aegis AI Control Plane** provides high-intensity orchestration and intelligence endpoints for offensive cyberdefense operations.

### Core Capabilities
* **Scan Orchestration**: Trigger and monitor complex pentest workflows driven by Temporal.
* **Vulnerability Intelligence**: Access detailed CVE analysis and misconfiguration data with technical evidences.
* **Real-time Streaming**: Persistent SSE (Server-Sent Events) for live status updates across the global scan fleet.
* **Zero Trust Auth**: Professional session management with JWT and HTTP-only cookie-based refresh tokens.
