# 🛡️ Aegis AI Control Plane API

The **Aegis AI Gateway** is the high-performance orchestration layer for the Aegis offensive cyberdefense platform.
It provides secure, unified access to scan orchestration, vulnerability intelligence, team management, and billing operations.

### 🚀 Core Missions
* **Automated Pentesting**: Trigger and monitor large-scale security scans powered by Temporal workflows.
* **Threat Intelligence**: Access technical proofs and CVE data extracted by specialized worker fleets.
* **Enterprise RBAC**: Manage multi-tenant organizations with granular roles (SuperAdmin, Admin, Billing, etc.).
* **Financial Governance**: Monitor token consumption, manage licenses, and track audit trails.

### 🔒 Security & Authentication
Aegis AI enforces a Zero-Trust architecture:
1. **Primary Auth**: JWT Bearer Token (short-lived).
2. **Session Persistence**: HTTP-only Secure Refresh Token (Rotation enforced).
3. **Permission Scopes**: Every endpoint is gated by specific RBAC scopes.
